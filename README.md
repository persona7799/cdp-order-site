# CDP 사이트: 홈페이지 → 구글 시트 주문

레버 95,000원 / 추가 고무 각 4,000원. 배송비는 주문당 4,000원 1회입니다. 고무만 주문해도 동일합니다. 구글 폼 연결은 제거했습니다.
사이트에서 주문자 이름·연락처·배송 주소를 입력하면 Netlify Function이 가격과 수량을 검증하고 Apps Script가 Google Sheet에 저장합니다. 저장 확인 후에만 주문번호를 표시합니다. 카카오톡과 결제 기능은 포함하지 않습니다.

## 1. 구글 시트와 Apps Script 연결 (판매자 계정에서 한 번)

1. 판매자 구글 계정으로 **새 스프레드시트**를 만드세요. 비공개로 유지하세요.
2. 시트 URL에서 `/d/`와 `/edit` 사이가 스프레드시트 ID입니다.
3. **확장 프로그램 → Apps Script**를 열고 `google-apps-script/Code.gs` 내용을 붙여 넣어 저장합니다.
4. Apps Script **프로젝트 설정 → 스크립트 속성**에 아래 두 값을 추가합니다.
   - `ORDER_SPREADSHEET_ID`: 위 시트 ID
   - `ORDER_SHARED_SECRET`: 비밀번호 생성기로 만든 32자 이상 무작위 비밀 문자열. 채팅/소스에 넣지 마세요.
5. **배포 → 새 배포 → 웹 앱**을 선택합니다.
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자** (로그인 없이 서버가 호출하기 위해 필요합니다. 비밀 문자열 검증으로 쓰기를 제한하며 시트 자체를 공개하지 않습니다.)
6. 본인 계정의 권한 승인 후 `/exec`로 끝나는 웹 앱 URL을 복사합니다.
   조직 정책상 모든 사용자 배포가 불가능하면 다른 서버 저장 방식을 사용해야 합니다.

## 2. Netlify 연결

**파일 드래그만으로는 서버 Function이 배포되지 않습니다.** 기존 Netlify 프로젝트에 Git 저장소를 연결하여 빌드하거나 Netlify CLI를 사용해야 합니다.

### 방법 A: Git 연결 권장
이 프로젝트 파일을 본인 Git 저장소에 올리고 기존 Netlify 프로젝트의 저장소 연결 메뉴에서 연결합니다. `netlify.toml` 설정이 적용됩니다.
- Build command: `npm run build`
- Publish directory: `public`
- Functions directory: `netlify/functions`

Netlify 프로젝트의 **Environment variables**에 다음을 등록하세요. Functions 런타임에서 사용할 수 있어야 합니다.
- `ORDER_SCRIPT_URL`: Apps Script 웹 앱 `/exec` URL
- `ORDER_SHARED_SECRET`: Apps Script에 설정한 것과 동일한 비밀 문자열

설정 후 새 배포를 실행합니다. 비밀값은 HTML/JS 파일에 넣지 않습니다.

### 방법 B: Netlify CLI
Node.js 20 이상이 설치된 컴퓨터에서 이 폴더를 열고:
```
npx netlify-cli login
npx netlify-cli link
npm run build
npx netlify-cli deploy --prod --dir=public --functions=netlify/functions
```
`link`에서 **기존 CDP 프로젝트**를 선택하세요. 위 환경 변수는 Netlify 설정 화면에서 먼저 등록하세요.

## 3. 연결 후 반드시 확인

1. 실제 공개 사이트에서 테스트용 정보로 레버 1개 + 고무 15 5개 + 고무 20 5개를 주문합니다.
2. 상품 합계 135,000원 + 배송비 4,000원 = 총 주문 금액 139,000원과 주문번호가 표시되는지 확인합니다.
3. 구글 시트의 `CDP 주문` 탭에 같은 주문번호와 수량이 한 번만 저장됐는지 확인합니다.
4. 응답 실패 시 같은 입력 내용으로 다시 제출하면 같은 요청 ID를 재사용합니다. 새로고침 후에도 입력이 동일하면 같은 요청 ID를 사용합니다. 개인정보 입력 자체는 브라우저 저장소에 저장하지 않습니다.
5. 테스트 행은 주문번호로 찾아 수동 삭제하세요.

시트의 앞쪽 열 순서와 이름은 변경하지 마세요. 오른쪽의 주문상태/입금확인/발송일/택배사/송장번호를 판매자가 관리합니다. 접수 성공은 결제 완료를 의미하지 않습니다.

## 로컬 확인
```
npm test
npm run build
```
브라우저 통합 실행은 `npx netlify-cli dev`로 가능합니다. 구글 연동 환경 변수가 없으면 실제 주문은 저장되지 않으며 오류를 안내합니다. 로컬 HTML 열기나 단순 정적 서버에서는 상품 선택만 확인할 수 있습니다.

## 운영 정보

- 동시 요청은 Apps Script 잠금으로 순서대로 처리하고 요청 ID로 중복 저장을 막습니다. 사용자가 입력을 바꾸어 새로 제출한 주문은 별개의 주문입니다.
- 서버가 가격을 재계산하고 입력한 문자열은 시트 수식으로 실행되지 않도록 저장합니다.
- 요청 처리량은 Netlify/Apps Script 할당량의 영향을 받습니다. 대량 주문 운영 전에는 스팸 방지 및 처리량 점검이 필요합니다.
- 개인정보 안내 문구는 초안입니다. 판매자 사업 정보, 실제 보관·파기 정책, 문의처, 입금 안내는 운영 전 확정해 반영하세요.
- 현재 재고 차감, 결제, 고객 주문 조회, 카카오톡 알림은 없습니다.
- 제품 사진은 대화의 참고 이미지이며 발송일은 제공받은 11월 2일 문구를 사용합니다.
